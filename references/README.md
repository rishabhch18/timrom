# Earlier prototypes and product research

The active shared application is the Angular app and backend at the repository root. These files preserve earlier source, design exploration and research; they are historical references, not additional production services. Current approved requirements and implementation status are in [the main documentation](../docs/INTEGRATION-STATUS.md).

- [One World](one-world/README.md): earlier React/Vite prototype and local backend, with tests and package locks.
- [Visual review](visual-review/README.md): graphics and motion comparison studio.
- [Avatar samples](avatar-samples/prompts.md): generated art directions and prompts.
- [Product discovery](product-discovery.md), [research and architecture](research-and-architecture.md), and [economy specification](economy-specification.md): planning history.
- [Project history](PROJECT-HISTORY.md): earlier workspace overview.
- `exploration.html` and preview images: early UI exploration.

Historical recommendations may have been superseded by the approved decisions in `../docs/`. Install dependencies separately if running an earlier prototype. Local account databases, runtime state, credentials, logs, dependencies and generated build output are intentionally excluded.
